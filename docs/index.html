Python · Game localization · Argos Translate

Game
Translator

Herramienta de escritorio y CLI para localizar diálogos de videojuegos a partir de archivos de texto reconocibles. Detecta estructuras habituales, traduce cadenas y prepara archivos de idioma sin tratar los recursos binarios propietarios como si fueran texto plano.

Código fuenteDocumentación e instalaciónPruebas de seguridad
01 / FORMATS

Formatos reconocidos

JSON, Ren'Py, CSV/TSV, RESX, gettext, INI, LANG, Yarn Spinner, Ink y texto plano, según las estructuras implementadas.

02 / ENGINE

Traducción offline

Argos Translate como motor local predeterminado. También admite un endpoint HTTP configurable y un modo noop para pruebas.

03 / SAFETY

Dry-run y restauración

Simulación sin cambios, creación de copias de seguridad para modificaciones in-place y restauración mediante manifiesto.

04 / WORKFLOW

Conservación de originales

Cuando existe una estructura de idiomas compatible, puede crear el idioma de destino sin sobrescribir los archivos originales ni traducciones ya existentes.

Importante: ejecuta primero --dry-run y conserva una copia externa del directorio del juego. La compatibilidad depende del motor y del formato; no procesa directamente paquetes binarios propietarios, archivos cifrados ni recursos Unity empaquetados.

Showcase informativo. No ejecuta traducciones en el navegador ni distribuye archivos de juegos. Comprueba las condiciones de uso del juego antes de modificar sus recursos.
